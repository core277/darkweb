Dark Web

A live chat + voice server you launch from a browser bookmark instead of typing a URL.

Install on iPad (Safari)

  1. Tap the Share icon on any page, then Add Bookmark. Save it (the name doesn't matter — e.g. "Dark Web").
  2. Tap and hold this link, then choose Copy Link — or use the copy box below instead, if that doesn't work:

    Launch Dark Web
  3. Open your Bookmarks list, tap Edit, tap the bookmark you just made.
  4. Clear its address field, paste (this replaces it with the copied code), then tap Done.
  5. On any webpage, tap that bookmark to open Dark Web.

Drag this link to your bookmarks bar, then click it on any page:

Notes

Voice calling needs microphone access, which browsers only grant on secure (HTTPS) pages. Launch Dark Web from an HTTPS page for voice to work. Some sites also block injected scripts via a strict Content-Security-Policy — if the bookmarklet does nothing, try launching it from this page instead.
